# Operation Counter

[![Последняя версия](https://img.shields.io/github/v/release/operationcounter/operation-counter-releases?label=%D0%B2%D0%B5%D1%80%D1%81%D0%B8%D1%8F)](https://github.com/operationcounter/operation-counter-releases/releases/latest)
![Android 10+](https://img.shields.io/badge/Android-10%2B-3DDC84?logo=android&logoColor=white)

**Operation Counter** — простое приложение для Android, которое помогает работнику вести учёт выполненных операций за день: сколько и каких операций сделано и сколько времени уходит на каждую.

Всё хранится на самом телефоне, регистрация не нужна, а считать можно и без интернета.

## Возможности

**Экран «Сегодня»**
- Список операций, из которого вы выбираете, что делаете сейчас. У каждой операции свой счётчик на текущий день.
- Быстрые кнопки **+1, +5, +10** и **+X** (ввод любого числа от 1 до 1000). Набор кнопок и их порядок можно настроить.
- Журнал изменений счётчика: время, добавленное число и скорость. Любую запись можно удалить, счётчик пересчитается.
- **Пауза** для перерывов: время паузы не учитывается при расчёте скорости.
- Плавная анимация счётчика, виброотклик и защита от случайного двойного нажатия.

**Скорость выполнения**
- Для каждого изменения счётчика рассчитывается, сколько времени ушло на единицу.
- Среднее по операции видно в карточке дня, а в истории по дням и за месяц.

**Раздел «История»**
- Все дни с выполненными операциями по месяцам.
- Итоги месяца по каждой операции с количеством и средней скоростью.
- Нажатие на операцию в конкретном дне открывает полный список изменений счётчика за этот день.

**Раздел «Настройки»**
- Добавление, переименование и удаление операций. 
- Настройка кнопок счётчика: числа, порядок, наличие кнопки «+X».
- «Начало дня»: можно указать, во сколько начинается новый день (удобно для ночных смен).
- Вибрация и тема оформления: светлая, тёмная или как в системе.
- Экспорт и импорт данных, проверка обновлений и сведения о версии.

## Установка

Приложение не из Google Play, поэтому ставится из файла.

1. Откройте страницу [последнего релиза](https://github.com/operationcounter/operation-counter-releases/releases/latest) на телефоне.
2. В разделе **Assets** скачайте файл `OperationCounter-….apk`.
3. Откройте скачанный файл. Если Android попросит, разрешите установку приложений из этого источника (браузера или файлового менеджера).
4. Подтвердите установку. Play Protect может показать предупреждение о приложении неизвестного разработчика, это нормальное поведение для файлов вне магазина.

**Требования:** Android 10 или новее. Работает в вертикальной ориентации.

## Обновление

- В приложении откройте **Настройки → О приложении → «Проверить обновления»**. Если вышла новая версия, появятся её номер, описание изменений и кнопка **«Скачать»**. Откройте скачанный файл и подтвердите установку.
- Можно и вручную: скачайте APK последнего релиза и установите его поверх текущего.

## Как пользоваться

1. На главном экране выберите операцию: появится её счётчик.
2. После каждой выполненной операции (или нескольких сразу) нажимайте кнопку с нужным числом. Для произвольного числа нажмите **«+X»**.
3. Нужно отойти? Нажмите кнопку паузы, а после возвращения кнопку «Дальше».
4. Чтобы добавить ещё одну операцию, выберите её в списке ниже. У каждой операции свой счетчик и кнопка паузы.
5. Если ошиблись, удалите запись крестиком в журнале изменений.
6. Итоги по дням и месяцам смотрите в разделе **«История»**. Данные в этом разделе нельзя редактировать.

При первой установке есть одна операция «Сборка». Добавьте свои операции в разделе «Настройки».

## Как считается скорость

- Скорость записи это время с предыдущего изменения (для первой записи – с момента, когда операция была выбрана), делённое на добавленное число. Время пауз вычитается.
- Пример: через 5 минут после предыдущей записи нажали «+10», значит, на штуку ушло 0:30.
- Среднее за день и за месяц считается по сохранённым скоростям с учётом количества, а не простым средним.
- Скорость показывает честное время, если вы ведёте одну операцию за раз. Если вы перемежаете операции и не ставите паузу, время между нажатиями включает работу над другой операцией.

## Резервная копия

Данные хранятся только на телефоне, поэтому при удалении приложения или очистке его данных они исчезнут. Регулярно делайте копию.

- **Настройки → Экспорт JSON** сохраняет все данные: операции, историю и настройки. Файл можно перенести на другой телефон.
- **Настройки → Импорт JSON** загружает данные из такого файла (текущие данные заменяются, приложение спросит подтверждение).
- **Настройки → Экспорт CSV** выгружает таблицу для Excel: дата, операция, количество, время работы и среднее время на штуку в секундах.

## Конфиденциальность

- Данные не отправляются никуда и не привязаны к учётной записи.
- Единственное обращение в сеть это проверка обновлений: приложение скачивает с этой страницы небольшой файл с номером последней версии. Личные данные при этом не передаются.
- Разрешения: интернет (только для проверки обновлений) и вибрация.

## Частые вопросы

**Данные пропадут при обновлении?** 
Нет, если ставить новую версию поверх старой.

**Можно ли пользоваться без интернета?**
Да, интернет нужен только для проверки обновлений.

**Почему в «Истории» нельзя исправить число за прошлый день?** 
Чтобы случайно не испортить уже накопленные данные: править можно только записи сегодняшнего дня.

**Что такое «Начало дня» в настройках?** 
Время, с которого записи считаются относящимися к новому дню. Например, при значении 05:00 записи, сделанные в 03:00, попадут в предыдущий день.

**Где исходный код?** 
Исходный код приложения не публикуется. Архивы «Source code», которые GitHub добавляет к каждому релизу автоматически, содержат только этот README.
